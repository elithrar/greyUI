# anti-slop upstream

Vendored from https://github.com/dmmulroy/anti-slop at commit `6d538555cb151d4121ed51a27db81890eacf8ae9`.

Only the generic production Oxlint plugin is vendored. Upstream test harness files and the optional Effect-specific plugin are intentionally omitted because greyUI does not execute them.

The vendored source is intentionally owned by this repository after import, per anti-slop's installation guidance.
